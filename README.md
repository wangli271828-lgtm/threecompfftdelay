# Julia 程序说明

本目录是一套以 Kagome 晶格为主的有限温辅助场／行列式量子蒙特卡洛（DQMC）程序。通过采样离散辅助场、更新费米子格林函数，计算能量、配对、电荷关联等物理量，并使用 MPI 汇总多个独立采样进程的结果。

## 文件分工

| 文件 | 作用 |
| --- | --- |
| `main.jl` | 程序入口：启动 MPI，依次执行初始化、预热、测量和结果输出。 |
| `initialize.jl` | 读取 `system.csv` 参数，建立晶格、辅助场、传播矩阵及各类工作区。 |
| `lattices.jl` | 构造晶格几何、跃迁矩阵、格点映射和更新位置；当前主流程针对 Kagome。 |
| `montecarlo.jl` | 正反向扫描虚时间，提出辅助场更新，计算 Metropolis 接受率，执行格林函数局部及延迟更新。 |
| `measure.jl` | 从格林函数测量能量、双占据、配对关联、CDW 关联、磁化率及可选的非等时观测量。 |
| `postprocess.jl` | 归一化统计量，计算结构因子、序参量和动量分布，进行 MPI 汇总并保存结果。 |
| `utilities.jl` | HS 分解、辅助场及工作区初始化、格林函数稳定重建、非等时传播、化学势调节和日志工具。 |
| `multiply.jl` | 定义工作区数据结构，实现 FFT 加速矩阵乘法、LDR 分解维护及稳定求逆。 |
| `Block.jl` | 定义块对角矩阵及左右乘法，用于各动量点的三子晶格矩阵运算。 |

## 计算流程

1. 从运行工作目录的 `system.csv` 读取参数，并分配内存。
2. 构造 Kagome 晶格：`L × L` 个原胞，每个原胞 3 个格点，总格点数 `Nlayer = 3L²`。
3. 将虚时间分成 `Interval` 片，`Δτ = β / Interval`；每个格点、时间片初始化一个四态辅助场。
4. 执行 `WarmStep` 次预热扫描；开启 `mutuner` 时，在预热前半段调节化学势以接近目标密度。
5. 执行 `MeasureStep` 次测量扫描，奇偶步交替正反向，每个时间片更新前进行等时测量。
6. 使用延迟更新提高效率，每隔 `P0` 个时间片通过 LDR 分解稳定重建格林函数；动能传播使用 FFT 加速。
7. 各 MPI 进程独立采样，结束后汇总并输出结果。

入口为 `main.jl`。运行前需准备对应 Julia 依赖和 `system.csv`；参数文件及以下输出路径均相对于运行工作目录。

## 主要输出

| 路径 | 内容 |
| --- | --- |
| `result.txt` | 参数、接受率、能量、序参量、双占据、磁化率、平均符号、统计误差字段及计时。 |
| `core/core-进程号.txt` | 各 MPI 进程的部分统计结果。 |
| `data.jld2` | 平均格林函数、距离配对关联、双占据直方图和动量分布等。 |
| `dataUEQ.jld2` | 开启非等时测量时保存的虚时间相关数据。 |
| `log-0.log` | 主进程标准输出。 |
| `log/error-进程号.log` | 各进程错误日志。 |

## 阅读提示

- 其他晶格构造函数属于保留分支，FFT 和测量流程仍针对 Kagome，不能仅切换 `latticetype` 就假定可运行。
- Kagome 的 `BondGroup` 存储 `(i, i)`，`UpdateBond!` 实际更新格点辅助场。
- 多个测量公式固定使用两自旋分量，不能将 `Ns` 直接视为完全通用的分量数设置。
- `MPIAverage` 的误差字段来自进程间标准差，不是均值标准误；`Density 1` 表示与目标密度的绝对偏差。
- 非等时磁化率当前先平均格林函数再计算矩阵乘积，其估计量正确性需要单独核查。
